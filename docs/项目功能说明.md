# TravelOS 旅行规划平台 · 功能说明

> 面向使用者的功能清单。
> 项目结构与技术选型见仓库根 `README.md`，架构细节见 `docs/architecture/`。

TravelOS 是一个**多人协作的旅行规划管理平台**，覆盖旅行前、中、后的完整生命周期：
行程规划 → 行囊准备 → 预订与凭证 → 途中记账 → 照片游记 → 行后统计。

---

## 一、认证与账户

- 账号密码登录 / 注册，登录态支持 `Authorization: Bearer` 与 HttpOnly Cookie 双通道
- 账户信息查看、**修改密码**（验证当前密码 + 新密码规则，当前设备保持登录）、账户注销（需密码 + 勾选二次确认，注销后数据保留 30 天）
- **偏好与显示**：主题 / 时区 / 距离单位 / 默认货币 / 日期格式 / 一周起始日 + 四项通知开关（行前提醒 / 文档到期 / 成员邀请 / 每周摘要），保存到账户、所有设备同步
- 未登录访问任意页面会自动跳转登录页，并在登录后回到原地址

## 二、总览（首页）

按 `travel-os-home.html` 设计稿实现，自上而下六个区块：

- **出发信息板（Hero）**：按时段问候 + 今日日期；右上角为**下一段旅程倒计时**（天数 / 目的地 / 出发日，可点进行程）；下方三格年度数据 —— 本年度段数、在路上天数、最远抵达目的地
- **统计四联**：旅行次数、累计花费、在路上天数、待打包物品数（每格带口径脚注）
- **行程地图（通栏）**：按行程天给标点配色并绘制路线，左上角显示「DAY 1 — N」与起｜中｜终站点，右上角为底图切换；「完整地图 →」跳转真实地图页
- **行程速览 + 最近花费**：左为最近行程行卡（缩略表情 + 日期区间 + 天数 + 目的地 + 状态胶囊），右为最近 5 笔花费（分类色点 + 类别 · 日期 + 金额）
- **最近照片 + 最近游记**：左为三列方图网格（hover 显示说明），右为游记卡（标题 + 日期 · 行程 + 摘要两行）
- 侧栏展示未读通知角标；数据来自 `GET /api/dashboard`、`GET /api/stats/overview` 与 `GET /api/trips/{id}/route`
- 四个列表区块在无数据时各自显示空态与引导按钮（签发旅程 / 去记账 / 去相册 / 写游记）

## 三、旅行管理（核心）

- 行程 CRUD，字段含目的地、日期区间、预算、描述、封面图
- 状态流转：`草稿 → 规划中 → 进行中 → 已完成 → 已归档`
- 收藏（置顶）、归档、一键复制行程
- 列表以登机牌卡片展示，支持按状态筛选与关键词搜索

## 四、成员协作

- 按用户名邀请成员加入行程
- 四种角色：`owner / 管理员 / 成员 / 观察者`，可在线改角色与移除成员
- 观察者为只读角色，所有写接口对其返回 403
- 带属主的内容（照片 / 文档 / 游记 / 清单）仅属主本人或管理员可修改、删除

## 五、行程安排（Itinerary）

- 按**行程日期区间一键生成"行程天"**
- 每天可设置自定义标题，时间轴按天分组展示
- 地点管理：类型标签、地址、起止时间、预算、备注
- 地点完成勾选、同日内排序、删除
- 当天有预订时显示预订徽标提示
- 地点搜索联想依赖高德「Web服务」类型 Key，未配置时降级为手工输入

## 六、行程地图

- 高德地图展示全部行程地点，标点按行程天配色
- 每日按**真实驾车路线**绘制路径，并给出该天的里程与时长
- 点击某天可聚焦该天路线（其余天淡化），支持标准 / 卫星底图切换
- 路线规划失败时自动降级为虚线示意，不影响标点浏览

## 七、费用管理

- 花费记录 CRUD，按 9+ 类别分类统计
- 三种分摊模式：**均分**（勾选成员）、**按比例**、**按金额**（尾差由付款人承担）
- 汇总面板：预算用量仪表（已花 / 预估）、记账笔数、人均花费
- 报表：分类环形图、每日柱状图、成员垫付与应付对比、类别预算进度
- **多人结算**：自动计算"谁该给谁转多少"的最少转账方案，可确认落档

## 八、预算管理

- 独立的行程预算视图，支持按类别设置与调整预算额度
- 与费用报表联动，超支类别给出警示

## 九、预订管理

- 五类预订：机票 / 酒店 / 火车票 / 门票 / 其他
- 机票与火车以航线票形式展示，酒店 / 门票 / 其他以信息格展示
- 类型特有字段（航班号、舱位、房型、免费取消截止、车次座位、场次等）
- 预订提醒：可设置提前提醒时长；酒店填写"免费取消截止"后自动派生提醒时间

## 十、凭证中心（Vouchers）

- 把行程内所有预订聚合成**出行现场速查凭证**
- 按时间正序排列，大字信息格 + 确认码 + 二维码，支持打印与分享
- 单独生成订单二维码，便于现场出示

## 十一、打包清单

- 多清单管理，按类别（衣物 / 洗漱 / 电子 / 药品 / 证件 / 其他）建清单
- **内置分类模板**，新建清单自动填充常用物品
- 物品勾选 + 数量 + 进度环（已打包 x/y），全部完成时显示 READY 印章
- 清单一键复制

## 十二、照片

- 上传照片（JPG / PNG / WebP，≤ 5 MB，支持多选与拖拽）
- 拼贴（保留原始比例）与网格两种视图，按行程天分组
- 设为**行程封面**、编辑说明与拍摄时间、大图预览

## 十三、旅行文档

- 上传护照 / 签证 / 保单等 PDF 或图片（≤ 10 MB）
- **到期时间 + 到期提醒开关**，7 天内到期标黄、已过期标红
- 支持在线预览（图片内嵌、PDF 内嵌）

## 十四、游记

- 撰写游记，草稿 / 已发布双状态，支持心情标记
- 可关联到具体"行程天"与"地点"，可勾选已有照片
- 列表以"卷首大卡 + 普通卡"排版，按心情色着色
- 阅读页提供沉浸式排版：首字下沉、拉引句、小标题目录、上下篇导航

## 十五、天气

- 按行程日期范围拉取逐日天气（温度区间、天气状况、降水概率）
- 数据自动缓存；无数据时显示占位提示，不影响其他模块

## 十六、数据统计

- 总览：旅行次数、累计天数、总花费、目的地数、平均天数、最常去目的地
- 年度对比、月度分布、费用分类占比
- 支持按年份切换，并可从年度明细表下钻到某一年

## 十七、PDF 导出

- 一键导出行程 PDF（行程天 + 地点 + 预订信息，内嵌中文字体）

## 十八、AI 旅行助手

- 多轮对话（会话列表 / 消息记录 / 删除）
- **行程草稿机制**：AI 生成的行程修改以草稿形式返回，用户可"应用"或"丢弃"，应用前需人工确认
- 未配置 LLM 三项环境变量时功能自动关闭

## 十九、通知中心

- 通知列表 + 分页，侧边栏展示未读角标
- 按时间分组、按类型与状态筛选
- 单条已读 / 全部已读 / 清除已读；高优先级通知标红
- 行程上下文胶囊可直接跳回对应行程

## 二十、其他

- 健康检查：`/api/health`、`/api/health/database`
- 账户页支持**导出个人数据 JSON**（含全部行程与子模块，照片与文档只导出元信息）

1. **高德「Web服务」类型 Key**：配置后即可启用行程安排的地点搜索联想（当前降级为手工输入）
2. **账户偏好设置**：~~主题 / 时区 / 单位 / 默认货币等偏好缺服务端接口~~ 已实现（2026-10-16）
3. **账户资料编辑**：修改显示名与头像缺接口（修改密码已实现）；导入数据按用户决定暂不实现
4. **注销用户数据清理**：`UserCleanupScheduler` 已预留（默认关闭），需先确定保留期限策略
5. **地点类型与费用类别的完整配色**：数据库枚举取值多于前端当前映射的子集，未覆盖的取值会回落默认样式
