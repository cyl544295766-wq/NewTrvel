### 同轮修复的两个真 bug

1. **行程详情天气永远显示「–」**——前端读的是 `w.icon / tempMin / tempMax / temp`，后端实际字段是 `condition / tempLow / tempHigh / rainChance / iconCode`。已改为正确字段，并补 `iconCode → emoji` 映射与「天气 + 降水概率」tooltip。
2. **`PATCH .../journals/{jid}/photos/reorder` 自写好起就是 500**——`trip_journal_photos` 是**复合主键 (journal_id, photo_id)、没有 `id` 列**，实体也没有 `@TableId`，MyBatis-Plus 因此不生成 `updateById`，运行时报 `Invalid bound statement`。已改为按复合键 `LambdaUpdateWrapper` UPDATE（无需加列或迁移）。
